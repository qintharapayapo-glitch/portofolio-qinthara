PORTOFOLIO QINTHARA RAISSA PUTRI PAYAPO

Isi proyek:
- index.html : struktur halaman website
- style.css  : desain dan tampilan responsif
- script.js  : interaksi sederhana
- assets/    : tempat menyimpan gambar

PENTING: Gambar asli dari screenshot Figma belum disertakan sebagai file terpisah.
Masukkan gambar milikmu ke folder assets/ dengan nama berikut:
1. foto-profil.png
2. poster-kegiatan.jpg
3. fara-course.jpg
4. buku-menu.jpg
5. idrila-logo.png
6. fara-logo.png
7. hoshi-logo.png
8. sertifikat.jpg
9. dapur-hwanip.jpg
10. ilustrasi.jpg

Kemudian buka index.html di browser.

PUBLIKASI GITHUB PAGES:
1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka Settings > Pages.
3. Pilih Deploy from a branch.
4. Pilih branch main dan folder /(root), lalu klik Save.
